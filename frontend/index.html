How the Agent Works
1. Website Discovery — DuckDuckGo search finds target company websites
2. Headless Browser Rendering — Playwright Chrome renders JS-heavy SPAs
3. CSS Card Extraction — Detects team member cards using 14 selector patterns
4. Schema.org JSON-LD Parsing — Extracts structured Person data
5. Team Page Detection — Auto-navigates to /team /leadership /about pages
6. Contact Subpage Crawling — Probes /contact /contact-us for emails
7. Groq AI Extraction — Llama 3.3 70B structures all data into clean leads
